# CupShuffle

カップの中に隠れた球の位置を当てる、ブラウザー向けのカップシャッフルゲームです。

## 起動方法

`index.html` をブラウザーで開いてください。

## ランキング

プレイヤー名と難易度ごとの最高連続成功数を、使用中のブラウザー内に保存します。各難易度の上位5件が表示されます。

名前を入力せずに開始した場合は、「名無し」としてプレイし、ランキングにもその名前で記録されます。

## 鬼ムズの解放

「激ムズ」で5連続成功すると、速度150msの「鬼ムズ」が解放されます。鬼ムズはページを再読み込みするか、プレイヤー名を変更すると再びロックされます。

プレイヤー名はページを再読み込みすると空欄に戻ります。ロック中の鬼ムズにカーソルを合わせると、解放条件が表示されます。

鬼ムズで5連続成功すると、専用ファンファーレ、虹色の発光、大量の紙吹雪、特別な称賛メッセージが表示されます。

## 開発者モードとランキングのリセット

1. ランキング欄の「開発者モード」を押します。
2. 開発者パスワード `sisa` を入力します。
3. 表示された「ランキングをリセット」を押します。
4. 確認画面で承認すると、全難易度のランキングが削除されます。

開発者モードはページを再読み込みすると解除されます。このパスワードは通常利用時の誤操作を防ぐためのもので、強固なセキュリティを提供するものではありません。
